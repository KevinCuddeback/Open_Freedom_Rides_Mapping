# Open_Freedom_Rides_Mapping
Construct an open-source, relational, spatiotemporal data ecosystem that documents Freedom Rides movement. Transforming historical narratives into precise geospatial "nodes and edges," and enable generation of accurate vectors for Wikimedia Commons, interactive academic maps, and deeply personalized "journey tracks" for individual riders.
